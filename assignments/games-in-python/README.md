
# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build the classic word‑guessing game using Python strings, loops, and user input. This exercise reinforces string manipulation, control flow, and basic I/O while providing a fun, interactive program.

## 📝 Tasks

### 🛠️ Setup Word List and Game State

#### Description
Create a predefined list of possible words and select one at random. Initialize variables for tracking guesses, progress display, and remaining attempts.

#### Requirements
Completed program should:

- Include a list of at least five candidate words.
- Choose a random word for each new game.
- Initialize the display with underscores representing unguessed letters and set a counter for remaining attempts.

### 🛠️ Game Loop and Player Interaction

#### Description
Implement the main loop that repeatedly asks the player for letter guesses, updates the on‑screen progress, and tracks incorrect attempts until the game ends.

#### Requirements
Completed program should:

- Prompt the user for a single letter and validate the input.
- Reveal correctly guessed letters in the progress display.
- Deduct an attempt for each incorrect guess.
- Terminate when the word is fully guessed or attempts are exhausted.
- Display a clear win or lose message and reveal the correct word.

### 🛠️ Optional Enhancements

#### Description
Add extra features to make the game more engaging or user‑friendly.

#### Requirements
Completed program could:

- Prevent the user from guessing the same letter twice.
- Show a list of letters that have already been guessed.
- Offer the player the option to play again after a game ends.
